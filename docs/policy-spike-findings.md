## Notes

- Latency is wall-clock from apply/refresh start to first successful verification of the effect.
- "Works" means the spike observed the intended enforcement or registry effect on this Server SKU.
- Forced logoff of an active session is not performed by Windows for logon-hours on a standalone box; the agent must call WTS APIs itself (see session-kick rows).
- Spike code lives under `e2e/policy-spike/` (`//go:build spike`); workflow: `.github/workflows/policy-spike.yml`.
- MS-GPREG delimiters `[` `;` `]` are single UTF-16LE code units (no trailing NUL); only key/value strings are NUL-terminated.
- Agent must bump `GPT.INI` Version on every desired-state change; `gpupdate /force` bypasses the version skip and is not a substitute for correct versioning.
- AppLocker CSE is discovered at runtime from `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\GPExtensions` (exact CSE GUID match first, fuzzy AppLocker/AppID name match only as fallback). Do not invent MMC tool GUIDs; when none is verifiable under GPExtensions, pair the CSE with the MS-GPOL NULL tool GUID `{00000000-0000-0000-0000-000000000000}`.
